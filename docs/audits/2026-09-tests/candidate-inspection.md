# Source, filesystem, and migration candidate inspection

This is an inventory of observed assertions, not a keep/delete decision. It covers tracked `*.test.*` and `*.spec.*` files selected by filesystem calls, source reading, migration wording, and legacy wording. Follow-up searches included child-process calls, raw imports, and source-string conversion. No `?raw` candidate was found.

The scan selected 49 files: 32 with filesystem/source/config indicators and 17 additional UI/form files with migration suite titles. The groups below contain 15 app architecture files, 6 app tooling files, 11 package wiring/config files, and 17 rendered component files. These are file counts, not executed test counts. Parameterized declarations and comments make simple textual `it` counts misleading; use runner collection for case totals.

Line references point into the inspected test itself. "Export shape" means inspecting imported keys or function types without exercising the exported behavior. "Rendered structure" means inspecting live DOM attributes/classes/nesting; it is not a source-text assertion, but its value under a behavior-only policy still needs review.

## Review implications established by inspection

A filesystem keyword does not establish that a whole test file is disposable. Package helper behavior, Node resolution, semver execution, built CSS, Vitest collection and LCOV generation occur inside flagged files. Conversely, a behavior-sounding title does not establish that behavior is exercised: SelectFormField's class prop contract is inspected as text, and the form error-title claim exceeds its assertion.

The file-by-file decision pass should distinguish source assertions, configuration shape, export shape, rendered structure, and executed behavior at the case level. This inspection does not decide which infrastructure/configuration contracts belong in the final suite, whether export-only checks have value, or whether particular class/slot attributes are public supported behavior. It also does not establish overlap with other tests or per-test coverage contribution.
