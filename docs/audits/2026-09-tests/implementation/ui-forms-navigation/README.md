# UI, forms and navigation behavior

Implementation for [issue 100](https://github.com/bc-solutions-coder/bcordes/issues/100), based on `94e2874`, implemented in `79168cb`. [dispositions.tsv](dispositions.tsv) maps all 159 original declarations to their retained behavior, replacements or deletions. The 69 accepted structural and duplicate declarations are removed or consolidated, including the forms and UI package scaffold files. Their public-import and runner guarantees now come from rendered consumers and the actual workspace execution tests from issue 91.

Forms use public package imports and real React Hook Form controllers. Tests observe label association, help and error descriptions, invalid state, rejected empty submission, corrected payload submission and stale-error recovery. SelectFormField submits the actual stored value and reports it through the trigger. The current trigger displays `mobile`, not `Mobile App`; cleanup does not invent a new label-mapping contract. The context-error test truthfully describes mounting without form context.

Navigation tests use the real memory router. They check supplied names and destinations, actual current-page semantics, custom item collections, brand/actions and empty collections. The exact-match matrix compares the same non-root destination with exact enabled and disabled at its own path and a child path. Mobile navigation reports public navigation and open-state changes, opens and dismisses the real sheet, and preserves parent control until dismissal is accepted. It does not claim that MobileNav closes itself after a link click.

Primitive tests preserve named controls, checked/selected states, disabled behavior, callbacks, dialog descriptions, content transitions and controlled overlays. They no longer assert source strings, class tokens, generated identifier formats, wrapper hierarchy, export inventories or migration markers. Tooltip tests assert controlled rendering, not pointer timing.

The browser fixture imports public packages, compiles Tailwind with the shared package theme and explicit package sources, and uses controlled geometry and data. It verifies button and badge variants, hover effects, all button sizes, caller borders, label color and disabled appearance, form trigger/popup customization, checkbox appearance, both switch sizes, progress fractions, separator direction, avatar success/failure and ring, every sheet side, and the mobile active-navigation distinction. The progress measurement uses painted geometry rather than requiring a width implementation. Avatar failure uses a real failed image response. The small checkbox snapshot was visually inspected and contains no text; its path is shared across platforms. Other checks use relative dimensions and computed presentation.

Omitting package utility scanning fails the measured variant/size scenario. Browser defects also prove sensitivity to a missing checkmark, wrong progress value, wrong sheet side/default, missing fallback/ring, discarded caller customization and missing switch motion. Thirty unit defects cover form relationships and values, destinations and exact matching, parent state and public callbacks, disabled controls, link semantics, progress and overlay content. An initial active-navigation probe put its override before spread props and had no effect; the corrected override failed the intended test.

All 1,059 unit tests and 50 browser tests pass, with no skips or browser retries. Coverage is unchanged in every measured file: 97.39% lines, 96.18% statements, 92.35% branches and 96.08% functions. Denominators, exclusions and all four 90% gates are unchanged. Build, typecheck, lint, formatting, documentation links and diff checks pass.

[resources.tsv](resources.tsv) registers new test-only files for final reconciliation. [summary.json](summary.json) records final commands, results, coverage comparison and defect evidence. [coverage-summary.json](coverage-summary.json) preserves per-file measurements. The first full run caught unused test imports through the real workspace typecheck test; those imports were removed. Both required reviews have zero remaining findings. Authenticated browser checks use synthetic local sessions and the built application, without a live identity provider or production credentials. Local results do not claim remote CI success.
