# Documentation

## Get running

- [Local setup](setup.md): install dependencies, start local services and run the app.
- [Configuration](configuration.md): find required settings, defaults and where values are supplied.

## Implement a change

- [Development](development.md): understand module ownership and add a feature.
- [Authentication](authentication.md): work with sessions, identity and access checks.
- [Wallow integration](wallow.md): call SDK operations and handle errors and query caches.
- [Notifications](notifications.md): work with live updates and notification actions.
- [UI and forms](ui.md): use shared components, form controls and theme tokens.

For example, start an inquiry action in the development guide, follow its authentication and SDK references, then use the testing guide to choose checks.

## Verify and operate

- [Testing](testing.md): choose checks and understand what they verify.
- [Deployment](deployment.md): register the app, deploy, verify and roll back.

[Domain terms](../CONTEXT.md) define the application's vocabulary. Plans and unfinished work live in [GitHub Issues](https://github.com/bc-solutions-coder/bcordes/issues).
