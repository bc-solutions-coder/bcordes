# Triage labels

Use these GitHub labels when assigning work:

| Label             | Meaning                                           |
| ----------------- | ------------------------------------------------- |
| `needs-triage`    | Needs maintainer review                           |
| `needs-info`      | Waiting for information from the reporter         |
| `ready-for-agent` | Specified and ready for autonomous implementation |
| `ready-for-human` | Requires human implementation                     |
| `wontfix`         | Will not be implemented                           |
